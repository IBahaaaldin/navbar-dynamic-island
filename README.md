## ✨ Features & Micro-Interactions

- **Clean Minimal Canvas**: Pitch black (`#000000`) or crisp white (`#ffffff`) canvas with zero distractions.
- **Dead-Center Ergonomics**: Positioned dead-center both horizontally and vertically across desktop and mobile screens.
- **Fluid Spring Morphing**: Expands smoothly from a compact resting pill into an expanded rich activity card using cubic-bezier spring physics.
- **Live Sound Waveform**: Animated CSS audio equalizer bars indicating real-time activity (`Building: Air Canvas ⚡`).
- **Zero Text Wrapping**: Strict `whitespace-nowrap` guarantees titles, names, and buttons stay unbroken.
- **Instant Theme Switcher**: Sun ☀️ / Moon 🌙 button dynamically changes the canvas between Dark and Light mode.
- **Mobile Responsive Drawer**: On small screens, expanding the island reveals structured navigation, project repo link, and contact buttons.
- **Self-Contained**: 100% pure HTML5 + Tailwind CSS CDN + inline SVGs with zero external dependencies.

## 🚀 Quick Start

### 1. View Locally
Simply clone and open `index.html` in your browser:
```bash
git clone https://github.com/IBahaaaldin/navbar-dynamic-island.git
cd navbar-dynamic-island
open index.html
```

### 2. Re-record Assets
To re-record desktop & mobile screenshots and videos:
```bash
node record.js
```
